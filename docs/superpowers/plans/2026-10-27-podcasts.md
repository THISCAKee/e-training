# Podcast Implementation Plan

**Goal:** Display YouTube podcasts through the homepage's existing Podcast control.
**Architecture:** Typed local catalog, server route and small client episode player.
**Tech Stack:** Next.js 16, React 19, Tailwind, lucide-react.
**Spec:** docs/superpowers/specs/2026-10-27-podcasts-design.md

## Constraints
Reuse the existing visual style. No new dependencies, database models or fabricated episodes.

## Review focus
Empty catalog must not create a broken iframe. Titles must be accessible. Player must preserve 16:9 on mobile. Episode changes must reset playback. Homepage control must navigate rather than show its old placeholder.
